# Алгоритмы сортировки

Программа на C# с графическим интерфейсом на Avalonia. В окне две вкладки.

**Внутренняя сортировка.** Пошаговый показ четырёх алгоритмов:

| Группа | Алгоритм |
|---|---|
| квадратичные | сортировка пузырьком с улучшениями, простые вставки |
| усовершенствованные | быстрая сортировка Хоара, пирамидальная (HeapSort) |

Массив рисуется столбиками, цвет показывает, что происходит с числом. Задержку между шагами задаёт ползунок, кнопка «Шаг» выполняет одно действие. Под графиком каждое действие объясняется простыми словами, справа ведётся журнал всех сравнений и перестановок со счётчиками.

**Сортировка слов.** Текст разбивается на слова, слова приводятся к нижнему регистру и сортируются в лексикографическом порядке, одинаковые слова оказываются рядом. Панель замеров сортирует наборы из 100, 500, 1000, 2000, 5000 и более слов и показывает среднее время по нескольким запускам. Таблицу можно сохранить в CSV и открыть в Excel.

## Запуск

Нужен .NET SDK 10 или новее.

```powershell
dotnet run --project src/SortingLab.App -c Release
```

Тесты:

```powershell
dotnet test
```

## Структура проекта

| Папка | Что внутри |
|---|---|
| `src/SortingLab.Core/Visual` | Алгоритмы для пошагового показа. Каждый реализует `IVisualSorter` и возвращает шаги через `yield return`: сортировка продвигается на одно действие каждый раз, когда интерфейс просит следующий шаг. |
| `src/SortingLab.Core/Words` | Разбиение текста на слова (`WordTokenizer`), быстрая сортировка слов (`QuickWordSorter`), подготовка наборов слов и замеры времени (`ExperimentRunner`). |
| `src/SortingLab.App` | Интерфейс: окно, две вкладки, график `BarChart`, модели представления. В `Assets/Fonts` лежит шрифт Roboto (Regular и SemiBold) под лицензией SIL Open Font License 1.1. |
| `tests/SortingLab.Tests` | Тесты алгоритмов, разбиения на слова и замеров. |

Алгоритм сортировки слов подключается так: класс реализует `IWordSorter`, а его экземпляр добавляется в `WordSorters.All`. После этого алгоритм появляется в списке на вкладке и получает свой столбец в таблице замеров.

## Методика замеров

- Перед замерами каждый алгоритм несколько раз сортирует небольшой набор, это время не учитывается.
- Каждый запуск сортирует новую копию одних и тех же слов.
- В таблицу идёт среднее время по запускам.
- Многоуровневая JIT-компиляция в приложении отключена, а библиотека с алгоритмами всегда собирается с оптимизацией. Поэтому все замеры идут на оптимизированном коде, в том числе в отладочной сборке.
